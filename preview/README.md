# Browser layout reference

This is a synthetic, legacy browser approximation of the touchscreen layout,
not the supported production service or an LVGL screenshot. Names and workout
records in `demo.mjs` are invented. No exercise images/animations are included.

`npm start` serves the loopback preview for development. It does not start the
production companions or flash a screen. Install the supported native V3 target
using [INSTALL.md](../docs/INSTALL.md). Do not expose a live-data preview publicly.
