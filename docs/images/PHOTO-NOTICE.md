panel. Andre explicitly requested its use in this README on 12 November 2026.
Only orientation correction, publication-size reduction and metadata removal were
performed. No screen content, person name, workout values or exercise artwork

privately; no EXIF/GPS/device metadata is included here.

installer's default media configuration. Visible names and workout values are
those already present in the maintainer's expressly authorized photograph; no
